# IM-DFrnt

SVG 도면과 IMDF를 편집하고 층별 길찾기 노드·엣지를 관리하는 macOS 앱입니다.

Xcode에서는 [IM-DFrnt/IM-DFrnt.xcodeproj](IM-DFrnt/IM-DFrnt.xcodeproj)를 열고, **IM-DFrnt → My Mac → ⌘R**로 실행합니다. 별도 프로젝트 생성 도구나 개발자 Team 설정은 필요하지 않습니다.

Swift 6를 지원하는 Xcode와 macOS 14 이상을 사용합니다. [자세한 빌드·실행 방법](IM-DFrnt/README.md#빌드와-실행)을 참고하세요.
