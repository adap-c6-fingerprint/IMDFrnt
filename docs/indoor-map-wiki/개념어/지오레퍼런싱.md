# 지오레퍼런싱

## 요약

지오레퍼런싱(georeferencing)은 실내 지도를 실제 지구 좌표계에 정렬하는 과정이다. 실내 공간도 지구 위에 있고 사람이 건물을 드나들기 때문에, 건물 풋프린트를 위·경도에 맞추고 Apple 위성 이미지와 정렬해야 정확한 실내 측위가 가능하다.

## 핵심 내용

- IMDF의 기본 요소는 건물 지면 풋프린트와 그것이 지구 상에 놓인 GeoCoordinates다.
- 정확한 실내 측위를 위해 IMDF는 서베이 가능한 walkable area를 갖고 Apple 위성 이미지와 정렬되어야 한다.
- 검증에서 에러가 없어지면 지오레퍼런싱·평가 단계로 넘어가고, Apple 실내 팀이 **수동으로** 지오레퍼런싱을 확인하며 validator로 드러나지 않는 결함도 점검한다.
- 변경이 생기면 새 IMDF로 저장되어 "Download Georeference to IMDF"에서 작업 리포트와 함께 제공된다.
- Apple 실내 팀의 수동 확인 이전, 도면 제작 단계에서도 지오레퍼런싱이 먼저 이뤄진다. [[FME]]/[[ArcGIS Indoors]] 같은 변환 도구가 "좌표계 정의 → 이동·회전·스케일 조정으로 도면을 실제 좌표에 정렬"하는 작업을 수행하며, 자세한 단계는 [[02) 도면에서 GeoJSON(IMDF) 추출 전 과정]] 참고.
- 지오레퍼런싱이 실제로 다루는 "점"은 IMDF 최종 산출물의 폴리곤 꼭짓점이 아니라 **컨트롤 포인트**(control point, from point/to point 쌍)다. 도면과 실제 좌표 참조 데이터 양쪽에서 식별 가능한 랜드마크를 사람이 수동으로 짝짓는 소수의 기준점으로, Esri ArcGIS Pro 공식 문서가 이 과정을 "Add Control Points"로 명시한다. 이 점들로 계산한 회전·스케일·이동 변환식이 도면 전체에 일괄 적용되며, 그 결과 최종적으로 지구 좌표를 갖게 되는 것은 폴리곤 꼭짓점뿐 아니라 라인스트링 끝점(Opening)·포인트 피처(Anchor 등)를 포함한 IMDF의 모든 geometry vertex다. 근거는 [[02) 도면에서 GeoJSON(IMDF) 추출 전 과정]]과 [[src06. CAD·BIM 도면에서 IMDF(GeoJSON) 변환 워크플로우 조사]] 7절 참고.

- 기준점이 **몇 개** 필요한지는 어떤 변환 모델을 쓰느냐로 정해진다. 컨트롤 포인트 쌍 하나가 방정식 2개(x·y)를 주므로 최소 쌍 수는 자유도÷2다 — 평행이동 1쌍, [[상사 변환]] 2쌍, [[어파인 변환]] 3쌍, 투영 4쌍, 2차 다항식 6쌍, 3차 다항식 10쌍. Esri 공식 문서의 요구치("three for a first-order affine", "six for a second order", "10 for a third order")와 일치한다.
- 최소 개수만 찍으면 식 수와 미지수 수가 같아 잔차가 항상 0이 되고, 사용자가 점을 잘못 찍어도 검출할 수 없다. 한 쌍 이상 더 찍어 과결정 상태로 만들어야 [[RMS 오차]]와 쌍별 잔차가 나온다. 배치도 한쪽에 몰지 말고 "코너마다 하나 + 내부에 몇 개"가 공식 권고다. 상세는 [[10) 지오레퍼런싱 기준점 — 몇 개를 왜 찍어야 하는가]] 참고.
- 지오레퍼런싱 기준점과 IMDF의 [[Anchor]] Feature는 별개 개념이다. Anchor는 최종 `anchor.geojson`에 저장되는 피처이고, 기준점은 파일에 남지 않는 계산용 입력값이다. 다만 도구에서 기준점을 "Anchor"라 부르는 것 자체가 잘못은 아니며, 지정 화면을 분리하면 혼동 없이 같은 이름을 쓸 수 있다.
