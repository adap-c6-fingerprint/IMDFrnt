# 좌표 정밀도

## 요약

좌표 정밀도(precision)는 **위경도를 소수점 몇 자리까지 기록하는가**를 말한다. [[수평 위치 정확도]](accuracy)와 이름이 비슷해 자주 혼동되지만 **전혀 다른 축**이다. 정밀도는 기록의 해상도이고, 정확도는 값의 신뢰도다.

## 핵심 내용

- OGC IMDF 1.0.0 Reference 원문: "Precision **SHOULD** be at least seven (7) decimal places." — "Seven (7) decimal places is equivalent to a planar distance of ~11mm which is tolerable for mapping and surveying purposes"
- **자릿수별 실제 거리**
  - 6자리 ≈ 10cm (RFC 7946 §11.2가 "a precision well within that of current GPS systems"라고 평가)
  - 7자리 ≈ 11mm (위도 1도 ≈ 110,540m 기준)
  - 경도 방향은 위도가 올라갈수록 짧아진다 — 위도 37도에서 1e-7도 ≈ 8.9mm
- IMDF는 RFC 7946이 실용적이라고 본 6자리보다 **한 자리 더** 요구한다.
- **자릿수를 늘려도 정확해지지 않는다.** RFC 7946 §3.1.10: "the number of digits of the values in coordinate positions **MUST NOT** be interpreted as an indication to the level of uncertainty." 소수점 12자리로 적어도 그 값이 5m 틀렸다면 여전히 5m 틀린 것이다.
- 반대로 **자릿수를 줄이면 정밀도를 잃는다.** 내보내기에서 `%.6f` 같은 포맷으로 반올림하면 그것만으로 IMDF 권고 위반이다. 언어의 기본 부동소수점 인코딩은 대개 자릿수를 잃지 않으므로, 별도 포맷팅을 넣지 않는 편이 안전하다.
- RFC 7946은 과도한 정밀도의 비용도 언급한다 — "Implementations should consider the cost of using a greater precision than necessary." 파일 크기와 처리 시간이 늘기 때문이다.
