# Apple 실내 측위

## 요약

Apple 실내 측위(indoor positioning)는 Wi-Fi 핑거프린팅과 IMDF의 좌표 정보를 짝지어, 기기가 네트워크 연결 없이 온디바이스로 실내 위치(블루닷)를 추정하는 기술이다. 빠르고, 저전력이며, 프라이빗한 것이 특징이다. 요약하면 "실내 지도 + Wi-Fi = 블루닷".

## 핵심 내용

- **원리(연못 비유):** AP 신호는 빗방울이 만드는 물결과 같다. 여러 신호의 물결이 겹쳐 만든 격자 각 칸에는 고유한 텍스처 패턴, 즉 **핑거프린트**가 생긴다. IMDF가 각 칸의 위도·경도·층 좌표를 제공하므로 좌표와 핑거프린트를 짝지을 수 있다.
- **동작:** 건물 진입 시 core location 서버에서 핑거프린트가 기기로 다운로드된다. 이후 Wi-Fi 라디오만 켜져 있으면 **네트워크 없이** 동작한다. 앱이 정확도 `best`로 요청하면 기기가 핑거프린트를 수동 관찰해 온디바이스 패턴 매칭으로 좌표를 도출하고, 로컬 센서로 갱신하다 임계값에서 다시 핑거프린트를 본다.
- **정확도:** 기대 신뢰 범위는 약 3~5m. IMDF에 테이블 같은 fixture를 포함하면 제약이 늘어 정확도가 올라간다.
- **활성화:** IMDF 로드 → 서베이 앱으로 Wi-Fi 수집 → core location 서버에 업로드·활성화 → 서베이 앱에서 품질 테스트.
- **표시:** Core Location 프레임워크 API로 사용자 실내 위치를 앱에 표시한다.
