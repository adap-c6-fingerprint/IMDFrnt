# 수평 위치 정확도

## 요약

수평 위치 정확도(horizontal positional accuracy)는 지도 데이터의 Feature가 **실제 지상 위치로부터 수평 방향으로 얼마나 어긋나 있는가**를 나타내는 품질 요건이다. IMDF는 이 요건을 `±5m 이내`로 **강제(MUST)**한다.

## 핵심 내용

- OGC IMDF 1.0.0 Reference 원문: "Features that explicitly reference this rule-set **MUST** be within +/- 5 meters of their actual ground location when tested using an independent source of higher accuracy."
- **규칙 세트 참조 구조.** IMDF는 이 규칙을 개별 Feature 페이지마다 반복하지 않고 Reference 페이지에 한 번만 정의한 뒤, 각 Feature의 `Geometry Capturing Rules`가 이를 참조하게 한다. 그래서 "어떤 Feature에 걸리는가"는 Reference 페이지만 봐서는 알 수 없다.
- **참조하는 Feature Type은 6종이다** — Venue, Level, Unit, Footprint, Fixture, Kiosk. 모두 "Horizontal positional accuracy MUST be within tolerance"를 명시한다.
- Opening·Detail·Section·Amenity·Anchor·Address·Occupant·Geofence·Relationship에는 **이 문장이 없다.** 요건은 공간 범위를 정의하는 폴리곤 계열에 집중돼 있다.
- **검증 방법이 규정에 포함돼 있다** — "an independent source of higher accuracy"로 테스트해야 한다. 즉 자기 데이터 내부의 일관성이 아니라 외부의 더 정확한 기준과 비교해야 한다.
- **[[좌표 정밀도]]와 다른 축이다.** IMDF는 정확도에 ±5m(MUST), 정밀도에 소수점 7자리(SHOULD)를 요구한다. "11mm 단위로 기록하되 위치는 5m까지 틀려도 된다"는 조합이 되는데, 기록의 해상도와 값의 신뢰도는 별개이므로 모순이 아니다.
- **Feature 단위 요건이지 데이터셋 평균이 아니다.** 원문이 "Features ... MUST be within"이므로, 평균이 좋아도 한 곳이 크게 어긋나면 그 Feature는 위반이다.
- 규칙의 배경은 위성·항공 영상 유도의 한계다. Footprint 페이지가 "Radial displacement would cause derived geometries to possess a shape and spatial extent with questionable horizontal positional accuracy"라고 적어 두었다 — 고층 건물을 비스듬히 찍으면 옥상이 옆으로 밀려 보이는 문제다.

### 잔차로 대리 판정할 때의 한계

- 지오레퍼런싱 도구가 보여 주는 [[RMS 오차]]는 **내가 찍은 짝들 사이의 일관성**이지 지상 위치와의 편차가 아니다. 엉뚱한 지점을 일관되게 찍으면 잔차가 0이어도 지상 위치는 크게 어긋난다.
- 따라서 잔차는 **필요조건 대리 지표일 뿐 충분조건이 아니다.** "이 값을 넘으면 만족하지 못할 수 있다"는 방향으로만 쓸 수 있다.
- [[NSSDA]]의 `Accuracy_r = 1.7308 × RMSE_r`로 ±5m를 되돌리면 RMS 상한 **2.889m**가 나온다.
- **실내 축척에서 ±5m는 실용적 합격선이 아니다.** 방 폭이 3~10m라 그만큼 어긋나면 방 하나를 통째로 옆방에 그린 셈이다. 실무 경계는 벽 두께(0.1~0.3m)에서 잡는다.
