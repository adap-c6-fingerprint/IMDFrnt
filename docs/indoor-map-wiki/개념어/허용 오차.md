# 허용 오차

## 요약

허용 오차(tolerance)는 **두 좌표 또는 두 끝점을 "같은 자리"로 볼 거리의 상한**이다. CAD 도면을 폴리곤으로 변환하는 모든 도구가 이 파라미터를 갖는다. 도면의 선분 끝이 정확히 만나는 일이 거의 없기 때문이다.

## 핵심 내용

### 왜 필요한가

- [[CAD 토폴로지]]의 결함 때문이다. 제도자가 벽 선을 문틀까지 끌어오다 몇 mm 못 미치거나 지나친 자국이 남는다.
- Esri의 설명 원문: "used to account for poor CAD topology—for example, **line gaps between doors and walls**"
- 이 틈을 그대로 두면 방을 둘러싼 선분들이 닫힌 고리를 이루지 못해 폴리곤을 만들 수 없다.

### 업계 도구의 기본값 — 전부 절대 물리 치수

| 도구/계층 | 파라미터 | 기본값 | 단위 |
|---|---|---|---|
| Esri Import CAD To Indoor Dataset | Door To Wall Distance | **0.3 international inch = 7.62 mm** | 인치 또는 mm |
| Esri Import Floorplans (폐기) | Door Close Buffer | 0 (= 기능 꺼짐) | 인치 |
| ArcGIS 지오데이터베이스 | [[XY Tolerance]] | **0.001 m (1 mm)** | "on the ground" |
| ArcGIS 지오데이터베이스 | XY Resolution | 0.0001 m (0.1 mm) | "on the ground" |
| FME AreaBuilder / Snapper | Snapping Tolerance / Distance | 없음 (기본 `None`) | ground units |

- Esri의 `Door To Wall Distance`는 데이터 타입이 `Double`이 아니라 **`Linear Unit`**이다. 값과 단위를 함께 입력하게 해, 이 값이 무차원 수가 아니라 **물리적 길이**임을 타입 수준에서 선언한 것이다.
- 허용 단위가 **인치 또는 밀리미터**로 한정된 것 자체가 다루는 오차의 규모를 말해 준다 — 밀리미터 규모의 접합부 오차다.
- **기본값 0을 "권장 허용 오차 0"으로 읽으면 안 된다.** 폐기 도구의 0은 수치 권고가 아니라 기능 꺼짐이다.

### 키우면 안 되는 이유

- 허용 오차를 키우는 것은 **정합성을 사는 대신 경계 정확도를 파는 거래**다.
- Esri는 명시적으로 말린다 — "Overriding the default XY Tolerance is **not recommended**", "it is best to use the default x,y tolerance values in all but extreme cases."
- 사용자가 "닫히지 않았습니다" 경고를 없애려고 값을 계속 올리는 것은 자연스러운 행동이지만, 그 결과는 **실제로 벌어진 곳이 닫힌 것으로 처리되는 것**이다.
- 일반적인 벽 두께가 100~300mm이므로, 허용 오차가 수십 mm에 이르면 붙어 있지 않은 벽이 붙은 것으로 판정되기 시작한다.

### 도면 크기 비례는 왜 틀렸는가

- 조사한 세 계열(Esri Indoors 도구, ArcGIS 지오데이터베이스, FME) **어디에도 도면 크기·범위·축척에 비례하는 허용 오차는 없다.**
- 틈의 크기는 **실제 건물의 물리 치수**에 좌우된다. 도면 파일의 좌표 범위와 무관하다.
- ASPRS 2014가 축척 연동 임계값을 폐기한 논리가 그대로 적용된다 — 축척은 버튼 한 번으로 바뀌지만 그 아래 데이터의 정확도는 바뀌지 않는다.
- **비례 방식이 위험한 이유는 특정 규모에서 우연히 맞기 때문이다.** 개발 중 쓰는 도면이 그 규모라면 잘 동작하는 것처럼 보이다가, 규모가 달라지면 급격히 무너진다.
- 근본 문제는 **[[도면 축척]]을 모른다는 것**이고, 비례 공식은 그 불확실성을 해결하지 않고 감춘다.

### 판정마다 값을 나눠야 한다

- **링 닫힘** — "이 끝점과 저 끝점은 같은 자리인가". 작아야 한다(mm 규모).
- **겹침** — "이 선과 저 선이 같은 벽인가". 더 클 수 있다(이중선 간격은 cm 규모일 수 있다).
- 하나를 통과시키려고 값을 키우면 다른 하나가 과민해진다.
