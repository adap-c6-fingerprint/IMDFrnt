# 전역 Footprint · Anchor · Level 정렬

관련 이슈: #74 / IMD-64

## 메인 화면에서 그리기

왼쪽 목록에서 `footprint` 레이어를 선택하고 현재 층 도면 위에 점을 찍는다. 시작점을 다시 누르거나 **닫고 저장**으로 마친다. GPS나 opening 완료 여부와 관계없이 먼저 작도할 수 있다. 기존 자석·꼭짓점 이동·개체 편집·속성 편집·휴지통을 그대로 사용한다.

Footprint는 건물 전체에서 하나의 편집 저장소를 공유한다. 어느 층에서 고쳐도 같은 Feature ID에 반영된다. 정렬된 층에서는 해당 층 좌표로 역변환해 보여준다. 기존 프로젝트의 층별 Footprint는 열 때 ID·원본 속성을 보존하며 자동 이전한다.

## Footprint에 GPS 설정

왼쪽 **Anchor 지정** 또는 **도구 → Anchor 지정 화면**을 누른다.

1. 왼쪽 Footprint의 꼭짓점·교점·변을 선택한다. 가까운 지점에는 주황색 자석 표시가 나타난다.
2. 오른쪽 지도에서 같은 위치를 찍거나 하단 경도·위도를 입력하고 **Anchor 추가**를 누른다.
3. 서로 일직선이 아닌 점을 최소 3쌍 지정한다. 4쌍 이상을 권장한다.
4. 하단의 기존 쌍을 선택하면 Footprint 지점과 GPS를 다시 지정할 수 있다. **새 Anchor**로 선택을 해제한다.
5. GPS 선택 중에도 지도 드래그·확대/축소를 사용할 수 있다. **GPS 찍기**를 끄면 클릭으로 Anchor를 추가하지 않는다. 장소 검색은 지도만 이동하며 Anchor를 생성하지 않는다.

GPS 변경은 연결된 모든 층의 위경도 변환에 반영된다. GPS 미완성·퇴화 상태에서도 작도는 보존하며 IMDF 내보내기는 차단한다.

## 층 정렬

왼쪽 **Level · Footprint 정렬** 또는 같은 이름의 도구 메뉴를 누른다. 전역 Footprint와 층별 `level` 외곽만 보인다. Level 외곽이 없는 층은 메인 화면에서 먼저 그린다.

1. 층을 선택하고 **대응점 지정**을 켠다.
2. 왼쪽 Level 점 → 오른쪽 Footprint 대응점을 고른다. 양쪽 모두 꼭짓점·교점·변 자석을 사용한다.
3. 서로 떨어진 점을 최소 2쌍 지정한 뒤 **대응점으로 정렬**을 누른다. 3~4쌍으로 정합을 확인할 수 있다.
4. **대응점 지정**을 끄고 파랑(Footprint), 주황(선택 층), 초록(다른 층)을 겹쳐 확인한다.
5. 층별 표시·불투명도를 조절한다. 이동·회전각·균일 크기 배율을 입력하거나 미세조정 버튼을 누른다. 수동 조정하면 그 층의 대응점 위치도 갱신된다.
6. 다른 층에 반복한다. 저장·Undo/Redo 대상이다.

원본 SVG와 태깅·노드의 로컬 좌표는 유지한다. 층 → Footprint → GPS 변환을 IMDF·길찾기 내보내기에 공유하며 반복 조정으로 원본이 누적 변형되지 않는다. 기존 **지도 정렬** 도구와 구분하며 Footprint 기준 정렬은 이 새 화면에서 진행한다.

## 검증

저장소 최상위에서 `cd IM-DFrnt && swift build` 후 같은 디렉터리에서 `.build/debug/IMDFrnt --footprint-selftest`로 전역 공유, 층간 편집, GPS, 대응점 정렬, 미세조정, Undo, 재열기, IMDF 재투영, 자석 및 기존 데이터 이전을 검사한다. 지도 타일·검색은 네트워크가 필요하며 CLI 검사에 실제 지도 클릭 검증은 포함되지 않는다.

프로젝트는 형식 버전 6으로 저장한다. 기존 v2~v5 파일은 읽을 수 있지만, v6 파일은 이전 앱에서 열 수 없다. 구버전 재저장으로 전역 Footprint·층 정렬 정보가 사라지는 것을 방지한다. 원본 프로젝트의 별도 백업을 권장한다.

표시/불투명도 변경이나 대응점 입력만으로는 층의 GPS가 바뀌지 않는다. **대응점으로 정렬** 또는 이동·회전·크기 변경을 적용한 층만 Footprint GPS를 사용한다. 이미 정렬한 층은 전역 GPS가 유효하지 않으면 내보내기를 차단하며 오래된 층 GPS로 되돌아가지 않는다.

서로 다른 좌표계의 기존 Footprint는 각 층 GPS를 거쳐 공유 평면으로 이전한다. 변환 불가능한 Feature는 원본 층에 보존하고 안내하며, 해결 전에는 IMDF 내보내기를 막는다. 전역 GPS 수정 시 이전을 재시도하고, 원본 층의 GPS를 수정한 경우 프로젝트를 다시 열어 재시도할 수 있다.
