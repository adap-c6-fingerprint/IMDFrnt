# 층별 참고 도면 (IMD-100 / #121)

한 층의 기본 도면은 유지한 채 참고 SVG/PNG/JPEG 한 개를 추가할 수 있습니다.

## 사용 방법

1. 층을 선택하고 **건물과 공통 층 관리 → 도면 레이어 → 참고 도면 불러오기**를 누릅니다. 메인 화면 왼쪽 아래 **기본·필터 레이어**에서도 불러올 수 있습니다.
2. 왼쪽 아래에서 기본/참고 도면의 표시 여부와 불투명도를 각각 조절합니다.
3. **화면에서 참고 도면 정렬**을 누릅니다. 건물 관리 창에서 눌렀다면 창이 닫히고 중앙 도면에 정렬 조절판이 나타납니다.
4. 중앙 화면을 드래그해서 참고 도면만 옮깁니다. 조절판의 방향 버튼, 이동 간격, 가로/세로 위치, 회전 각도, 배율 입력 및 확대/축소 버튼으로 미세 조정합니다. 이동 값은 위경도가 아닌 기본 도면 좌표이며 회전/배율은 참고 도면 중심 기준입니다.
5. **완료**를 눌러 IMDF 작도로 돌아갑니다. **정렬 초기화**는 기본 도면 영역에 중앙 맞춤한 처음 상태로 되돌립니다. 드래그 한 번은 실행취소 한 번으로 되돌릴 수 있습니다.

## 표시와 자석

- 아래부터 기본 도면 → 참고 도면 → IMDF 작업 도형 순서입니다. 기존 SVG 개체로 태깅한 IMDF 작업도 참고 도면 위에 표시합니다.
- 참고 SVG 내부의 꼭짓점·끝점·교점은 정렬된 위치에서 작도/꼭짓점 이동/임시 문 자석으로 사용할 수 있습니다. 참고 도면의 SVG 개체 자체를 기본 도면의 태깅 대상으로 가져오지는 않습니다.
- PNG/JPEG 또는 벡터가 없는 SVG는 이미지 오버레이만 제공하며 이미지 인식으로 자석점을 생성하지 않습니다.
- 참고 도면을 숨기거나 불투명도를 0%로 하면 참고 도면 자석도 꺼집니다.
- 지도/GPS 정렬 화면의 원본 도면 Anchor 작업과 전역 Footprint 정렬은 별도 기능입니다.

## 저장과 호환성

- 참고 파일은 프로젝트 안에 내장됩니다. 위치·회전·배율·표시 설정은 층별로 저장되며 참고 도면 교체 시 초기화됩니다.
- 정렬 필드가 없는 기존 프로젝트는 기존과 같은 중앙 맞춤으로 표시됩니다. 기존 선택적 `referenceDrawing` 안에 선택적 `alignment`만 추가하며 프로젝트 형식 버전은 바꾸지 않습니다.
- 참고 도면은 편집 보조 자료입니다. 참고 도면을 정렬/교체/삭제해도 기본 SVG, IMDF 작업 좌표, GPS Anchor, 길찾기 노드·엣지 및 IMDF 출력 도형은 바뀌지 않습니다.
- 새 정렬 필드를 모르는 구버전 앱은 참고 도면 정렬을 유지할 수 없습니다. 이 기능을 사용한 프로젝트는 최신 앱으로 편집하세요.

## 병렬 작업

PR #122의 노드 그룹 모델/저장 버전/라우팅 편집기는 수정하지 않습니다. 테스트는 기존 도면 로딩 검사에 연결하며 진행 기록도 이 문서로 분리합니다.
