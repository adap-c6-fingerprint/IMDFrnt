# 이전 UX 시안

[review-prototype.html](review-prototype.html)은 대화 중 만든 후보 카드·방향 버튼 비교 시안의 원본이다. 실제 지도나 매칭 엔진에 연결되지 않은 HTML 개념 예시다.

시안은 당시 출입구 방향을 시각 단서로 사용했다. 이후 사용자가 출입구 대응을 클라이언트 범위로 제외했으므로 이 표현은 현재 구현 요구가 아니다. 원본 보존을 위한 참고 자료로만 사용한다.

현재 UX 요구는 [백로그](../BACKLOG.md)와 [#13](https://github.com/adap-c6-fingerprint/IMDFrnt/issues/13)에 기록했다. 생성된 후보 전환, 북쪽·카메라·축척 유지, 확정·보류·해당 없음 동작을 따른다.
